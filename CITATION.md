# How to cite JARI-PROTACS

Please cite the version-specific Zenodo software record when JARI-PROTACS contributes to an analysis, figure, workflow, or result:

> The Schürer Lab. (2026). *JARI-PROTACS: Joint Analysis for Reproducible Interface Clustering* (Version v0.1.0) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23374556

- [Open the Zenodo DOI](https://doi.org/10.5281/zenodo.23374556)
- [Download RIS](JARI-PROTACS-v0.1.0.ris)

The RIS file imports into Zotero, EndNote, Mendeley, and other reference managers.
